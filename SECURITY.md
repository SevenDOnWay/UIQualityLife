# Security Policy

## Supported Versions

We provide security updates and fixes for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The UIQualityLife team values the security of our users and developers. If you discover a security vulnerability or exploit within this project, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to **ngodaloc2006@gmail.com** with details about the vulnerability.
3. Include the following details if possible:
   - Type of vulnerability (e.g., command injection in CLI scripts, unsafe deserialization, insecure bridge server communication).
   - Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
   - Potential impact of the vulnerability.
   - Any suggested mitigations or patches.

---

## Response Process

- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will confirm the vulnerability and assess its severity.
- **Fix & Disclosure:** We will work on a fix in a private branch, tag a patched release, and publish an advisory acknowledging your responsible disclosure.
